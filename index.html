用語のインデックス

Agentic loopエージェンティックループ
プロンプト → コンテキストを集める → アクションを実行する → 結果を検証する → 完了、あるいはもう一周。02
Context windowコンテキストウィンドウ
Claude の作業メモリ。上限に達すると自動で圧縮され、細部は要約に置き換わる。05
Toolsツール
エージェントの動作の基盤。テキストを返すだけの AI との分かれ目。02
Permission modes権限モード
手動 / 自動承認 / プランモード。Shift+Tab で循環する。03
Plan modeプランモード
読み取り専用ツールだけで調査し、実行可能な詳細プランを返す。軌道修正に最適な場所。04
CLAUDE.mdメモリファイル
セッションのたびに自動で読まれ、内容はプロンプトに追記される。プロジェクト／ユーザーの2階層。06
Subagentサブエージェント
独立したコンテキストウィンドウで働き、要約だけを返す。中間作業は破棄される。07
Skillスキル
名前と説明だけが常駐し、依頼にマッチしたときだけ全体が読み込まれる Markdown。08
MCPModel Context Protocol
外部のツールとデータソースにつなぐオープン標準。ツール定義は常時コンテキストを占める。09
Hooksフック
ライフサイクルの節目で必ず走るコマンド。唯一の決定論的な制御手段。10
