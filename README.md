# 学習ノート — 公式コースを日本語で読む

Anthropic の公式コースを中心に、日本語で再構成した**静的な学習ノートサイト**。
ビルドツールなし・依存パッケージなし・素の HTML/CSS/JS だけで動く。

公開先: <https://good-creation.github.io/claudestudying/>

## 開く

```bash
python3 -m http.server 8791 --directory .
open http://localhost:8791/
```

`index.html` を直接開いても読める。外部依存は Google Fonts だけで、
オフラインならヒラギノ等にフォールバックするので崩れない。

ただし**解答集（`answers/`）だけは `file://` では動かない**。
本文の復号に Web Crypto を使うため、`https://` か `http://localhost` が要る。

## 収録しているもの

`index.html` がコースを選ぶ玄関。6系統ある。

|---|---|---|---|

**出典が違うものを混ぜない**のがこのサイトの方針。公式コース由来のページだけが
レッスン番号を持ち、それ以外は独立したファイル名にして、末尾に必ず出典セクションを置いてある。

## 読み方のしかけ

**タイムライン。** 動画が出典のページは、動画の実タイムコードを構造の軸にしている。
左端のレールがスクロールに追従して、いま読んでいる位置を動画の経過時間で示す。
ページ末尾に英語の全文トランスクリプトをそのまま収録している。

**用語ツールチップ。** 専門用語には点線の下線がつく。カーソルを合わせる（スマホならタップ）と、
やさしい言い換えが吹き出しで出る。本文の HTML には手を入れず、`assets/terms.js` の辞書から
実行時に当てている。

**小問題。** 各セクションの末尾に3択の自己チェックが入っている（全ページ合わせて253問）。
採点はしない。`<details>` だけで作ってあり、JS を使わない。

**試験。** [`quiz.html`](quiz.html) は Claude Code 入門コースの試験。標準22問に加えて、
レベル1〜3のチャレンジ4セット（計40問）を選んで受けられる。
[`github/quiz.html`](github/quiz.html) は GitHub コース専用の18問。

- **本番モード** — 全画面になり、サイト内の移動リンクが隠れる。他のタブに切り替えると
  その瞬間に問題文を隠し、離席した回数を記録して結果に出す
- **練習モード** — 目隠しなしで解ける
- どちらも**採点するまで正誤・得点・解説を一切出さない**。提出して初めて全問がまとめて開く
- 合格ラインは80%。結果に得点ランク（S / A / B / C）が出る

**解答集。** [`answers/`](answers/index.html) に試験62問の正解と解説がある。
合言葉を入れるまで読めない（本文は AES-GCM で暗号化してあり、ソースを見ても読めない）。
問題バンクを書き換えたら `node tools/build-answers.mjs` で生成し直すこと。

**読んだ記録。** 開いたレッスンをこの端末の `localStorage` に控えて、トップに
「つづきから」の1行を出す。サーバーには何も送らない。ログインもない。

## 合言葉について

`educators/` と `cloudflare.html` は、開くと合言葉の入力画面が出る。

**これは中身を守る仕組みではない。** 公開リポジトリの GitHub Pages で配信しているので、
HTML や画像の直リンク、ソース表示、GitHub 上のファイル閲覧、検索エンジンのクロールは
どれもこの画面を通らない。JS を切れば素通りする。
目的は「一覧からうっかり開かない」ことだけで、その前提で採用している。

解答集（`answers/`）のほうは本文そのものを暗号化しているので中身は読めないが、
合言葉が4桁である以上、総当たりはできる。こちらも秘匿が目的ではなく、
「答えがうっかり目に入らないこと」を狙っている。

## 出典

  本文は YouTube の自動生成字幕から取得した英語トランスクリプトと、公式コース本文を

## 手を入れるとき

```bash
python3 tools/validate.py       # リンク・画像・タイムラインの整合性
python3 tools/check-quiz.py     # 小問題の構造・丸写し・位置参照の検査
```

書き方の約束事、ページの構造、デザインのトークン、やってはいけないことは
[CLAUDE.md](CLAUDE.md) にまとめてある。**新しいページやコースを足す前に必ず読むこと。**
