# Claude Code 入門コース — 学習ノート

Anthropic 公式の Claude Code 入門コース（YouTube 動画10本 + [claude.com/courses](https://claude.com/courses) の本文）を、
日本語で再構成した静的な学習ノートサイト。ビルド不要・依存パッケージなし。

## 開く

```bash
python3 -m http.server 8791 --directory .
open http://localhost:8791/
```

`index.html` を直接開いても動きます（外部依存は Google Fonts のみ、オフラインではヒラギノにフォールバック）。

現在位置を動画の経過時間で示します。ページ末尾に英語の全文トランスクリプトを収録。
