WHATまず一言で

一言でいうと、何なのか

あなたのパソコンの中で、プログラムを読み、書き直し、命令を実行してくれる道具です。

たとえるなら

ふつうの AI はレシピを読み上げてくれる人。Claude Code は台所に一緒に立って包丁を持ってくれる人です。

やっていることは、この4つです。

  • ファイルを読む
  • ファイルを直す
  • 命令を実行する
  • 他の道具とつなぐ

使える場所はいくつもあります。このコースはターミナル（文字で命令を打ち込む黒い画面）を前提にします。

  • ターミナル
  • Visual Studio Code
  • Claude デスクトップアプリ
  • ウェブ
  • JetBrains の開発ソフト
確認 Claude Code の説明として、この節がいちばん大事にしているのはどれですか。
  • 教えるだけで終わらず、自分でファイルを開き、書き換え、命令まで動かすこと
  • プログラムのやり方を、言葉で分かりやすく教えてくれること
  • 動かせる場所がターミナルからウェブまで幅広いこと

答え: A — 手を動かすところまでやるのが、この道具のいちばんの特徴です。

動かせる場所がいろいろあるのは前置きとして出てきただけで、正体を説明する部分ではありません。

DIFFくらべる

チャットの Claude と、どうちがうの？

ちがいは頭の良さではありません。あなたのファイルに直接さわれるかどうかです。

「コピペの往復がなくなる」のは結果です。理由は、Claude Code がファイルを開いて書き換えられる立場にいること。この立場をエージェントと呼びます。

確認 Claude Code だとコピペの往復がなくなるのは、なぜですか。
  • コピペを省くための便利機能が別についているから
  • ファイルそのものを開いて書き換えられる立場にいるから
  • チャット版より返事が速く返ってくるから

答え: B — 人が受け渡しをしなくてよくなるのは、本人がファイルにさわれるからです。

コピペが消えるのは結果であって、原因はどこまで手が届くかというちがいにあります。

AGENTかなめの言葉

「エージェント」って何のこと？

「考える → やってみる → 結果を見る」を、ゴールに着くまでくり返せるソフトのことです。

まわりに働きかけて、決められたゴールに向かって行動できるソフトウェア。

— 公式コースでの説明
たとえるなら

数学の問題と同じです。解き方を思いつき、計算し、見返して確かめる。ちがっていたら、もう一周。

ゴールに近づくために、道具や外のサービスを使うこともあります。

確認 エージェントのいちばんの特徴として説明されているのは、どれですか。
  • やってみて、結果を見て、必要ならもう一度やる、を自分で回せること
  • 質問に一度で正確に答えきる力が高いこと
  • 外のサービスに接続する権利を持っていること

答え: A — ゴールに着くまで同じ輪を回し続けられることが核心です。

外のサービスを使えるという話は、そのあとに足されたおまけの説明として出てきます。

CANできること

実際に、何をしてくれるの？

読む・直す・動かす・調べるの4つを、自分でやります。

  • プログラムを読んで、説明してくれる

    「この機能は何をしているの？」「この不具合の原因を探して」と頼めます。

  • 関係するファイルをまとめて直してくれる

    ひとつ直すと他も直さないと動かない、という波及する範囲まで面倒を見ます。

  • 命令を実行して、その結果で次を決める

    やって終わりではありません。出てきた結果を見て、次の一手を自分で決めます。

  • ウェブで調べてくれる

    新しい情報が必要なら、自分で調べに行きます。

確認 「命令を実行する」の説明で、とくに強調されているのはどんな点ですか。
  • 実行した記録をあとで見返せるように残しておくところ
  • いくつもの命令を同時にまとめて走らせられるところ
  • 出てきた結果を見て、次に何をするかを自分で決めるところ

答え: C — 動かしただけで終わらず、その出力を次の判断の材料にします。

この動きがあるから、ゴールに着くまで輪を回し続けることができます。

CARE心がまえ

使う前に知っておきたい3つ

覚えられる量には限りがあり、勝手には進めず、そしてまちがえることがあります。

Memory

覚えていられる量には限りがある

一度に頭に置ける量をコンテキストウィンドウと呼びます。かなり多く持てますが、全部は無理です。だから丸ごと読み込まず、必要なところだけ探し当てます。

Permission

勝手には進めない

そのままの設定では、命令の実行やファイルの書き換えの前に必ず確認します。主導権はあなたにあります。

Caution

まちがえることがある

完璧ではありません。

  • 言いたいことを取りちがえる
  • 新しい不具合を持ち込む
  • 必要以上に複雑なやり方をする

いま何をしているか見ておくと、早く気づけます。

確認 Claude が一度に頭に置いておける量について、正しい説明はどれですか。
  • 確認のしかたを切り替えると、置いておける量が増える
  • 上限がないので、プログラム全体をいつも読み込んでいる
  • けっこうな量を持てるが、それでも全部を一度には持ちきれない

答え: C — 多くを持てても、限りはあります。

だから丸ごと読み込むのではなく、必要な場所を探し当てるやり方をとります。この話は「机の広さ」の回でくわしく扱います。
