LOOP部品 01

ぐるぐる回る仕組み

頼んでから終わるまで、同じ輪を何周も回っています。

  • あなたが頼む

  • 必要な情報を集める

    ファイルを読んだり、命令を走らせて様子を見たり。

  • 実際にやってみる

    ここではじめて手が動きます。

  • 結果を見て、確かめる

    自分の仕事を自分で見直すのが、エージェントの特徴です。

  • 終わる、またはもう一周

    足りなければ最初に戻ります。

大事なのは、この輪が閉じた自動機械ではないこと。回っている途中でも、情報を足す・止める・方向を変えるができます。

たとえるなら

ロボット掃除機です。ちがうのは、こちらは途中で「そっちじゃない」と言えるところ。

確認 この輪について、正しい説明はどれですか。
  • いったん動き出すと、終わるまで人は手を出せない
  • 一周したら必ず終わりで、二周目に入ることはない
  • 回っている最中でも、人が情報を足したり方向を変えたりできる

答え: C — 途中で割り込めることが、この仕組みの前提になっています。

確かめた結果が足りなければ最初に戻るので、一周で終わるとも限りません。

MEMORY部品 02

覚えていられる量

Claude が一度に頭に置いておける量のこと。作業机の広さだと思ってください。

会話・読んだファイル・命令の結果が、ぜんぶこの机に積まれます。いっぱいになると、Claude Code は会話を短くまとめて場所を空けます。

ここに落とし穴

まとめられた部分は、もとの言葉のままでは残りません。「さっき言ったよね？」が通じなくなるのは、これが理由です。

だから忘れてほしくないことは、会話ではなくファイルに書いておきます（→ 06）。

確認 置いておける量がいっぱいになったとき、何が起きますか。
  • そこで作業が止まり、はじめからやり直すことになる
  • それまでの会話が短くまとめ直され、細かい部分は残らないことがある
  • 置いておける量が自動で広がり、前の内容もそのまま残る

答え: B — 短くまとめて場所を空けるので、細かいところは落ちます。

だから忘れられたら困る前提は、会話の中ではなくファイルに置いておくほうが確実です。

TOOL部品 03

道具を持っている

ふつうの AI は文章を返すだけ。道具があると、その間に実際の行動が入ります。

  • ファイルを読む
  • ファイルを書き換える
  • 命令を実行する
  • ウェブを検索する
  • …ほか

しかも、決まった手順を再生しているのではありません。話の意味を見て、いまどの道具を呼ぶかをそのつど決めています。

確認 道具について、この節が「ふつうの AI とのちがい」として挙げているのはどれですか。
  • 返す文章の量が多くなり、説明がくわしくなること
  • 文章を返すだけの間に、実際の行動が入ること
  • 使える言語の種類が増えて、対応の幅が広がること

答え: B — 受け取って返すだけの間に、手を動かす段階があるかどうかが分かれ目です。

しかも、どの道具をいつ呼ぶかは決まった手順ではなく、そのつど意味を見て判断されます。

PERMIT部品 04

どこまで勝手にやらせるか

Shift+Tab で切り替わる、「どこまで確認なしで進めてよいか」のスイッチです。

  • 手動 — 毎回たずねる

    ファイルの書き換えも命令の実行も、そのつど確認します。よく知らないプログラムを触るときに。

  • おまかせ編集 — 書き換えは確認なし

    ファイルの書き換えは自動で進み、命令の実行はたずねます。あとでまとめて読む前提のときに。

  • 計画モード — 何も書き換えない

    読むだけで調べて、やり方の案を出します。手をつける前に方針を見たいときに。

確認を飛ばすときは慎重に

何でも確認なしにすると速くなります。ただし失っているのはまちがいに気づくための時間です。

確認 何でも確認なしで実行させたときに失うものは、何だと説明されていますか。
  • まちがいが起きる前に気づいて止められる機会
  • あとから設定を変えられる自由
  • 実行した内容を記録として残す仕組み

答え: A — 速さと引きかえに、割り込む時間そのものがなくなります。

だから、よく知らないプログラムを触るときほど、毎回たずねる設定のほうが向いています。
