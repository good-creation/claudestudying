同じ説明を、もうしない

チームの書き方のきまりを、あなたは何度説明したでしょうか。見直しのたびに指摘の形を説明し直し、記録を残すたびに好みを思い出させている。スキルは、それを一度で終わらせる仕組みです。

08 スキルとは何か
もとの出典

PAIN困りごと

毎回、同じ説明をしている

毎回おなじことを言い直している。そこが出発点です。

  • チームの書き方のきまりを説明する
  • 見直しのときの指摘の形を説明し直す
  • 記録を残すときの好みの書き方を思い出させる

そして一行で切ります。スキルはこれを解決します。

確認 スキルが解決しようとしている困りごとは、どんなものですか。
  • 同じ説明を、場面が来るたびに何度もし直していること
  • 説明した内容が、途中で書き換えられてしまうこと
  • チームの人数が増えると、指示が届かなくなること

答え: A — くり返しをやめるための仕組みです。

書き方のきまりも、見直しの形も、記録の残し方も、毎回言い直す必要がなくなります。

WHAT正体

一度書けば、あとは自動

やり方を一度だけ書いておくと、関係する場面で自動的に使われます。

スキルとは、何かのやり方を Claude に一度だけ教えるためのファイル。Claude はその知識を、関係する場面で自動的に使う。

— 公式コースでの説明

Claude Code では SKILL.md という名前のファイルが実体です。

たとえるなら

職場の壁に貼ってある作業手順書です。ふだんは目に入りませんが、その作業をする場面になると自分から見に行く。

確認 スキルはどんなタイミングで使われますか。
  • 始めるたびに、必ず最初から読み込まれる
  • 頼まれた内容が、そのスキルに関係するときに自動的に
  • スキルの名前を打って呼び出したときだけ

答え: B — 名前を指定しなくても、場面が合えば自分から使われます。

いつも読み込まれているわけではないのが、あとで出てくる他の仕組みとのちがいです。

TRIGGERかなめ

「説明文」がすべてを決める

スキルにつけた説明文が、それを使うかどうかの判断材料になります。

  • あなたが「この変更を見直して」と頼む

    スキル名を出す必要はありません。

  • Claude が、手元のスキルの説明文と見くらべる

  • 当てはまったものだけを開く

ここから導かれる、大事な書き方

中身がどれだけ良くても、説明文が実際の頼み方の言葉と噛み合わなければ一度も使われません。本当の仕事は、中身より「どんなときに使うか」を説明文に書くことです。

確認 スキルを作るとき、いちばん気をつけるべきなのはどこですか。
  • どんなときに使うのかが、説明文から伝わるようにすること
  • 中身をできるだけ短くまとめること
  • ファイルを置く場所を、深い階層にしないこと

答え: A — 頼み方の言葉と噛み合わなければ、中身が良くても呼ばれません。

使うかどうかの判断は、説明文を見て行われるためです。

WHERE置き場所

誰のためのスキルか

そのスキルを必要とするのが誰かによって、置き場所が変わります。

  • 自分用 — どのプロジェクトにもついてくる

    記録の書き方、資料のまとめ方、説明のしかたの好み。

  • プロジェクト用 — 関わる人全員に自動で行きわたる

    チームの決まり、会社の表記ルール、使う書体や色。

06 のメモ帳と、まったく同じ考え方です。

確認 スキルの置き場所は、何によって決まりますか。
  • 自分だけに効かせたいのか、チーム全員に届けたいのか
  • そのスキルの中身が、どれくらいの長さになるか
  • そのスキルを、どれくらいの頻度で必要とするか

答え: A — 届けたい相手が誰なのかで、置き場所が分かれます。

プロジェクトのメモ帳を置き分けるときと、同じ考え方です。

COMPARE使い分け

メモ帳・スキル・自分で打つ命令のちがい

ちがいは「いつ読み込まれるか」です。

スキルは、ふだんは名前と説明文しか読み込まれません。不具合を追っているときに、見直し用のチェックリストが机に居座っている必要はありません。

確認 メモ帳とスキルの、いちばん大きなちがいはどこですか。
  • 書ける内容の種類が制限されているかどうか
  • チームで共有できるかどうか
  • 毎回読み込まれるか、場面に合ったときだけ開かれるか

答え: C — 常に効かせたい決まりと、その作業のときだけ要る知識で使い分けます。

ふだんは名前と説明文だけなので、置いておける量をむだに使いません。

RECAPまとめ

この回のまとめ

いちばん効くのは、特定の作業に使う専門的な知識です。

  • チームで守っている見直しの基準
  • 好みの記録の書き方
  • 会社の表記や見た目のきまり

同じことを Claude に何度も説明していると気づいたなら——それは、書かれるのを待っているスキルだ。
