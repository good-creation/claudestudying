このコースの読み方

Claude Code は、パソコンの中で、あなたの代わりにプログラムを書いたり直したりしてくれる道具です。むずかしそうに見えて、やっていることは単純です。読むときは、次の3つだけ意識してください。

  • 01 から順に読む

    あとの回は、前の回に出てきた言葉をそのまま使います。とばすと急にむずかしく感じます。

  • 各節の最後にある「確認」で手を止める

    3択の問題が置いてあります。点数はつきません。答えを見る前に、自分で選んでみてください。

  • 物足りなくなったら、くわしい版へ移る

    各ページの最後に、対応するくわしい版へのリンクがあります。英語の元の発言もそちらに。

点線がついた言葉

点線の下線がついた言葉は、カーソルを合わせる（スマホならタップ）と短い説明が出ます。

この版について

もとになっているのは、Anthropic 公式の Claude Code 入門コースです。話題・順番・結論は、このサイトのくわしい版とそろえてあります。

公式の「やさしい版」ではありません

Anthropic がやさしい版を出しているわけではありません。これは公式コースの内容をこのサイトが独自に書き直したものです。言いかえやたとえ話は、読みやすさのためにこちらで足しています。

  • やさしくするために変えたこと

    専門用語を言いかえ、たとえ話を足し、一文を短くしました。英語の原文と、動画の時間に沿った並びは入れていません。

  • 変えていないこと

    公式が言っていない事実は足していません。コマンド名やファイル名は、実際に使うものなのでそのままです。
