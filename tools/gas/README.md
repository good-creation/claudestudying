# 修了証メールの送信役（Google Apps Script）

このサイトは GitHub Pages の静的配信なので、ページ自身はメールを送れない。
送信だけを Google Apps Script のウェブアプリに任せる。**あなたの Google アカウントの
Gmail から送信される**（無料。消費者向けアカウントは 1 日 100 通が上限）。

```
[ブラウザ] 採点完了
   │  POST（点数・合否・復習レッスン番号・氏名だけ）
   ▼
[Apps Script ウェブアプリ]  ← 合言葉 + 送信数の上限
   │  MailApp.sendEmail()
   ▼
[受験者のメール受信箱]  ← 修了証
```

## 手順（10分ほど）

1. <https://script.google.com/> を開き、**新しいプロジェクト**を作る。名前は「確認問題 修了証」など
2. 既定の `Code.gs` の中身を全部消し、このフォルダの **`Code.gs` を丸ごと貼り付ける**
3. 冒頭の設定を書き換える
   - `TOKEN` — 好きな文字列。あとで `assets/result-mail.js` の `TOKEN` と**同じ値**にする
   - `SITE_URL` — 公開URL（例 `https://good-creation.github.io/claudestudying/`）。
     空のままだと、メール内のレッスン名がリンクにならない
   - `SENDER_NAME` — 差出人の表示名
4. **デプロイ → 新しいデプロイ → 種類「ウェブアプリ」**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**（ログインなしのブラウザから叩くため）
5. 初回は権限の確認が出る。「詳細」→「安全ではないページに移動」→ 許可
   （自分のスクリプトに Gmail 送信を許可する操作）
6. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/……/exec`）をコピー
7. `assets/result-mail.js` の先頭を書き換える
   ```js
   var ENDPOINT = 'https://script.google.com/macros/s/……/exec';
   var TOKEN    = '手順3で決めた文字列';
   ```
8. 確認問題ページを開き、自分のアドレスを入れて練習で1周する。届けば完了

コードを直したら、**毎回「デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン: 新バージョン → デプロイ」**
が必要。保存しただけでは公開中の URL は変わらない。

## 動作の確認

- ブラウザで `……/exec` を直接開くと `{"ok":true,"service":"quiz-certificate"}` が返る
- 送れないときは Apps Script の「実行数」画面にログが残る

## この作りの限界（承知のうえで使う）

- **URL と合言葉はブラウザから見える。** 静的サイトである以上、隠せない。
  合言葉は機械的ないたずらを弾くためのもので、秘密ではない
- 歯止めは送信数の上限で掛けている。既定は「同じアドレスへ 6 時間に 5 通」「全体で 1 日 80 通」。
  `Code.gs` の `MAX_PER_ADDR` / `MAX_PER_DAY` で変えられる
- **クライアントから自由文は受け取らない。** 点数・合否・レッスン番号は型と範囲を検証し、
  氏名だけが自由文（40字・URL と改行は除去）。メール本文の骨格は Apps Script 側にある
- 受信者の記録は残していない（送信数の集計だけ）。名簿を作りたくなったら、
  スプレッドシートへの追記を `doPost` に足すことになるが、その時点で個人情報を預かる話になる
- Gmail の 1 日 100 通制限に達すると、その日は送れない
