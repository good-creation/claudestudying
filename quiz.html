Q01 出題範囲 — 01 Claude Code とは何か

Claude.ai と Claude Code の、最も本質的な違いはどれか。

解説

コピペの往復が消えるのは結果であって、原因は「環境の中で動く」というアーキテクチャの違い。

Q02 出題範囲 — 01 Claude Code とは何か

AI エージェントを実現する、最も基本的な方法はどれか。

解説

一問一答ではなく、判断と実行と観測を回し続ける構造のこと。

Q03 出題範囲 — 02 どう動いているのか

エージェンティックループの流れとして正しいものはどれか。

解説

検証で意図を満たしていなければループの先頭に戻り、結果が完全で検証可能になるまで繰り返す。

Q04 出題範囲 — 02 どう動いているのか

コンテキストウィンドウが上限に近づくと何が起きるか。

解説

この過程で細部が失われることがある。残したい前提は会話ではなくファイルに置くほうが安全。

Q05 出題範囲 — 02 どう動いているのか

ツールを持たない一般的な AI アシスタントの説明として正しいものはどれか。

解説

ツールがあることで「タスク完了に近づくために、いつコードを実行すべきか」を判断できるようになる。

Q06 出題範囲 — 03 最初のプロンプトを書く

自動承認（accept edits）モードでも、それでも確認を求められるのはどれか。

解説

編集の往復だけが消え、影響の大きいコマンド実行には必ず止まる、という線引きになっている。

Q07 出題範囲 — 03 最初のプロンプトを書く

プランモードでできないことはどれか。

解説

読み取り専用ツールだけで調査する。だからこそ安全に方針を固められる。

Q08 出題範囲 — 04 探索 → 計画 → コード → コミット

「一つだけ持ち帰るなら」と強調されるワークフローの順序はどれか。

解説

これを飛ばして直接コードを書かせにいくから、あとで軌道修正が増える。

Q09 出題範囲 — 04 探索 → 計画 → コード → コミット

軌道修正に最も適した場所はどこか。

解説

計画段階での修正は、書かれたコードを直す作業と比べて桁違いに安い。

Q10 出題範囲 — 04 探索 → 計画 → コード → コミット

Claude が自分の結果に自信を持つために必要なものはどれか。

解説

計画を書く段階で成功基準を明示する。基準がなければ「たぶんできた」以上の判断はできない。

Q11 出題範囲 — 04 探索 → 計画 → コード → コミット / 11 Review & Ship

コミットする前に推奨されることはどれか。

解説

サブエージェントは別コンテキストで動くので、書いた本人が持っているかもしれない偏りを引き継がない。

Q12 出題範囲 — 05 コンテキストを管理する

/compact を使うべき場面はどれか。

解説

新しい機能に移るなら /clear。以前の会話が新しい作業にバイアスを持ち込むのを避けるため。

Q13 出題範囲 — 05 コンテキストを管理する

/context を実行すると分かることはどれか。

解説

System tools が大きければ MCP の入れすぎ、Messages が大きければ会話が長すぎる、と原因を切り分けられる。

Q14 出題範囲 — 05 コンテキストを管理する

短く曖昧なプロンプトについて、正しいものはどれか。

解説

明確な指示がなければ、コードベースをより多く探索し、自分で推論する必要が出てくるため。

Q15 出題範囲 — 06 CLAUDE.md ファイル

CLAUDE.md の内容はどう扱われるか。

解説

書いた分だけ毎回のプロンプトが長くなる。だから短く保つことが効いてくる。

Q16 出題範囲 — 06 CLAUDE.md ファイル

CLAUDE.md の始め方として推奨されるのはどれか。

解説

そうするとファイルがコンパクトに、必要な情報だけに保たれる。準備ができたら /init で生成させる。

Q17 出題範囲 — 07 サブエージェントとは何か

サブエージェントを使うことの代償はどれか。

解説

「旅路なしで答えを得る」の裏返し。要約に含まれなかったものは、メイン側には存在しない。

Q18 出題範囲 — 08 スキルとは何か

Claude がスキルを使うかどうかを決める材料はどれか。

解説

依頼の内容と、利用可能な全スキルの description を突き合わせてマッチしたものが起動する。だから「いつ使うか」を description に書くのが実質的な仕事になる。

Q19 出題範囲 — 09 MCP で外部につなぐ

MCP サーバーについて、見落としやすいコストはどれか。

解説

/mcp で接続中を確認し、使っていないものは無効化する。CLI で代替できるならそちらのほうがコンテキスト効率が高い。

Q20 出題範囲 — 10 フックで確実に実行させる

PreToolUse フックが終了コード 2 を返すとどうなるか。

解説

単に止めるだけでなく理由が伝わるので、Claude は別の手段を取り直せる。0 は続行、その他はブロックしないエラー。
