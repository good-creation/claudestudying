KEY要点

重要なポイント

本コースは、AI を技術として理解するだけでなく、人間と AI の協働に焦点を当てている。

AI活用力とは、AI システムと効果的、効率的、倫理的かつ安全に関わることを意味する。

— Anthropic 公式 AI Fluency コース

AI活用力フレームワークは、委任力（Delegation）、記述力（Description）、評価力（Discernment）、倫理的責任（Diligence）の「4D」能力を中心に据えている。目標は、AI 技術が進化しても有用であり続ける、持続的な能力を身につけること。

効果的な AI 協働には、実践的な能力と、AI との協働に対する根本的な考え方の転換の両方が必要になる。

Claude Code 入門コースとの対応（推測）

4D の各能力は、本サイトの Claude Code 入門コースの内容と近い場面で登場する。以下は原文が明示した対応ではなく、こちらの推測による対応づけ。委任力 → 07 サブエージェント（作業を任せる判断）、記述力 → 03 最初のプロンプトを書く（意図を正確に伝える）、評価力 → 11 Review & Ship（出力を見極める）。
