このレッスンの内容

このレッスンを終えると、次のことができるようになる。

  • 記述力と評価力を実際のプロジェクトに適用する

  • 記述と評価の生産的なフィードバックループに取り組む

  • 人間とAIの協働を通じて成果を生み出す

    どちらか一方だけでは達成できない。

TRY演習

記述・評価のフィードバックループによるプロジェクト実行

講座5で計画したプロジェクトに取り組み、これまで身につけてきた記述と評価の能力を使って、学んだことすべてを実践していく。

  1. プロジェクト計画を見直す

    講座5で作成したプロジェクト計画を開く。どのタスクが人間の専門知識、AI の能力、または協働から恩恵を受けるかについてのデリゲーション決定を素早く見直す。それ以降に学んだことに基づいて、計画を自由に改善する。

  2. 記述のアプローチを準備する

    Claude との会話を始め、一緒に取り組むプロジェクトを説明する。実行に入る前に、記述へのアプローチを計画する。

    • 成果物の記述 — 各タスクで Claude からどのような成果物が必要か。どのような形式、スタイル、長さ、詳細レベルを求めているか。
    • プロセスの記述 — Claude は各タスクにどのようにアプローチすべきか。従ってほしい特定の方法、フレームワーク、またはステップはあるか。
    • パフォーマンスの記述 — このプロジェクト中、Claude にどのような協働行動を求めるか。簡潔か詳細か、挑戦的かサポート的か、アイデア重視か分析重視かなど。

    これらの質問を Claude と話し合い、協働のための明確な期待を設定する。

  3. 記述・評価のフィードバックループを使用してプロジェクトを実行する

    Claude と一緒に計画したプロジェクトタスクに取り組む。各タスクについて、次の記述・評価のループを完了するまで続ける。

    1. 記述する — 学んだ記述力を使って、必要なものを明確に記述する。何が欲しいかを具体的に伝える（成果物）。Claude がタスクにどうアプローチまたは考えるべきかを導く（プロセス）。プロセス中に Claude にどのようにやりとりに関わってほしいかを指定する（パフォーマンス）。
    2. 評価する — 受け取ったものの品質を評価する。出力された成果物そのものを評価する（成果物の評価）。Claude がタスクにどのようにアプローチしたかを評価する（プロセスの評価）。Claude の行動がニーズに対して最も役立つものかどうかを検討する（パフォーマンスの評価）。
    3. 改善する — 評価に基づいて改善する。何がうまくいき、何がうまくいかなかったかについてフィードバックを提供する。必要に応じて記述を明確にしたり調整したりする。結果に満足するまで反復して依頼する。
    4. 統合する — 自身の専門知識と判断を統合する。独自の視点、創造性、またはドメイン知識を加える。何を残し、修正し、破棄するかについて最終決定を下す。最終的な成果物に対する責任を負う。
