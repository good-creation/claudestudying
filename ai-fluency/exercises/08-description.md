# 演習 — 08 記述力 (Description)

## 不十分なプロンプトの改善

### 指示

1. Claude に『不完全なプロンプト』を提示してもらい、それを改善する練習をします。
2. 記述の考え方を適用して、それぞれを改善します：
   - **明確な成果物の記述**（求める内容を具体的に）
   - **プロセスの記述**（Claude にどのようにアプローチしてほしいか）
   - **パフォーマンスの記述**（協働中に Claude にどのように振る舞ってほしいか）
3. 改善前と改善後のバージョンについて Claude と話し合い、改善された記述がより良い応答の提供にどのように役立つかについてフィードバックを求めます。
4. 約5分後に役割を交代し、Claude が改善するための不十分なプロンプトを提供します。Claude が追加しがちな情報とその整理方法に注目します。

> **補足（演習原文外）** — 次のレッスン「09 効果的なプロンプト技法」の振り返りに、この演習を再度行って技法を実践するよう促す記述がある（`09-prompting-techniques.html`）。
