### 修正済み：`.tip` に原文を入れていた件

`.tip` は**こちらの補足を隔離する枠**であって、原文を入れると原文と補足の区別が読者から見て逆転する。
当初 4 箇所で原文が `.tip` に入っていたため、いずれも地の文（`<strong>ラベル：</strong>` 付きの段落）に戻した。

| 箇所 | 中身 | 原稿の出どころ |
|---|---|---|
| `01-introduction.html` | 事前準備（5〜10分） | `01-introduction.md` |
| `06-delegation.html` | 「注意」実際に Claude と会話をする | `06-delegation.md` |
| `10-discernment.html` | 「ゲームの時間」への誘導 | `10-discernment.md` |
| `13-conclusion.html` | 「何を発見したか教えてください」 | `13-conclusion.md` |

あわせて `10-discernment.html` の「ゲームの時間」は**サイト内に実体が無い参照**だったので、
`.warn` で未収録である旨を明記した。
